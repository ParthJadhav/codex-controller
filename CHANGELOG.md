# Changelog

All notable changes to Codex Controller are documented here.

## 0.2.0

- Rebuilt the application with Electron, React, Three.js, and a Swift native
  bridge.
- Added direct interactive DualSense geometry, layered profiles, action
  sequences, touchpad pointer control, stick rotation, light and haptic
  feedback, diagnostics, and guarded Codex shortcut/keymap integration.
- Added universal arm64 and x86_64 macOS packaging, Developer ID signing, Apple
  notarization, DMG and ZIP release artifacts, checksums, and an SBOM.
- Open-sourced the maintained product under the MIT License as Codex Controller.
